# 말랑말랑 명화 벽돌깨기

물감 튜브 벽돌을 붓으로 깨면서 명화 조각을 모으는 귀여운 브라우저 게임이에요.
10라운드를 모두 깨면 숨어 있던 명화 전체와 작품 해설이 공개됩니다.

**플레이:** https://ya6156.github.io/cute-brick-breaker/

## 조작
- 마우스·터치로 팔레트 이동, 탭하면 붓 발사
- 키보드: ← → 이동 · 스페이스 발사 · P 일시정지 · M 소리
- 반짝이는 금색 뚜껑 물감은 두 번 맞아야 터져요

## 수업용 팁
- 매 판 아래 세 작품 중 하나가 무작위로 나옵니다. 3·6·9라운드를 깨면 작품 힌트가 나와요.
- 특정 작품으로 고정하려면 주소 뒤에 붙이세요.
  - 고흐 「별이 빛나는 밤」: `?art=starry`
  - 호쿠사이 「가나가와 해변의 높은 파도 아래」: `?art=wave`
  - 모네 「인상, 해돋이」: `?art=monet`
